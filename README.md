# Турнирный бот PUBG / CS

Telegram-бот для дружеского чата, который ведёт турнирную таблицу PUBG и CS. Вместо ручного подсчёта убийств и побед в переписке всё вбивается кнопками прямо во время игры: бот копит историю матчей, считает таблицу, лигу за всё время и делает разбор от GPT.

Один Python-процесс, SQLite-файл, long polling. Для дружеского чата этого достаточно.

## Как это работает

1. `/бот` открывает меню.
2. `🏆 Новый турнир` — мастер из четырёх шагов: название → игра (PUBG/CS) → режим (соло/командами) → состав. Один раз в начале вечера.
3. Дальше бот сам ведёт табло текущего матча: `➕` у игрока — засчитать убийство (спросит жертву), `−` — отменить последнее, `🏆` — взял топ (соло) или `🏆 Победила А/Б` (команды).
4. `✅ Матч сыгран` — сохраняет катку, публикует обновлённую таблицу и сразу открывает табло следующего матча с тем же составом. Весь вечер — только кнопки.
5. `🏁 Завершить турнир` — финальная таблица, матрица «кто кого убивал», титулы вечера, разбор от GPT, голосование за MVP.

Смерти не вбиваются — бот считает их сам: `смерти = сыграно матчей − топов` (не взял топ = умер).

## Функции

- Таблица турнира: победы, убийства, KD, смерти, топы — с процентами от общего
- Матрица «кто кого убивал» + «любимая жертва»
- Титулы вечера (Чемпион, Мясник, Снайпер, Танк, Клоун, Курица, Немезида)
- Текущие серии побед/поражений в конце каждого матча
- Лига за всё время: очки = топы×3 + убийства×1, ранги от 🥉 Бронзы до 👑 Легенды
- Прогнозы перед стартом турнира и подсчёт точности при завершении
- MVP-голосование по итогам турнира
- Разбор от GPT: оценки 0–100 (хладнокровие / жестокость / игровой интеллект) + текстовые выводы
- Необязательные подколы от GPT после каждого матча (фоном, не тормозят игру)
- Гости, которых нет в чате (`➕ Добавить игрока`) — участвуют наравне со всеми
- `/undo` (кнопка в истории) — отменить последний сохранённый матч

## Команды

Всё доступно через `/бот` (меню на кнопках). Прямые команды — как ярлыки:

- `/бот`, `/menu` — главное меню
- `/table`, `/таблица` — таблица текущего турнира
- `/match`, `/матч` — табло текущего матча
- `/league`, `/лига` — лига за всё время
- `/analyze`, `/разбор` — разбор от GPT
- `/about` — что умеет бот

## Настройки чата

В меню `⚙️ Настройки` можно выключить (по умолчанию всё включено):
- 🤖 Подколы от GPT после матчей
- 🔮 Прогнозы перед турниром
- 🗳 MVP-голосование

## Переменные окружения

- `BOT_TOKEN` — токен бота от `@BotFather` (обязательно)
- `TZ` — часовой пояс, по умолчанию `Europe/Moscow`
- `DB_PATH` — путь к SQLite-файлу, по умолчанию `/data/bot.sqlite3`
- `LOG_LEVEL` — уровень логов, по умолчанию `INFO`
- `OPENAI_API_KEY` — ключ OpenAI для разбора и подколов; без него `/analyze` вернёт понятную ошибку, а подколы просто не будут приходить
- `OPENAI_SUMMARY_MODEL` — модель для разбора, по умолчанию `gpt-5-mini`

## Локальный запуск

Нужен Python 3.12+.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
BOT_TOKEN=... DB_PATH=./dev.sqlite3 OPENAI_API_KEY=... python -m bot.main
```

Тесты:

```bash
pytest
```

## Запуск на Railway

1. Залей проект в GitHub
2. Создай проект в Railway из репозитория — Railway соберёт контейнер по `Dockerfile`
3. Добавь volume, смонтируй в `/data`
4. Переменные: `BOT_TOKEN`, `TZ=Europe/Moscow`, `DB_PATH=/data/bot.sqlite3`, `LOG_LEVEL=INFO`, `OPENAI_API_KEY` (опционально)

Без volume база SQLite потеряется после каждого redeploy.

## Настройка Telegram

1. Создай бота у `@BotFather`, получи `BOT_TOKEN`
2. Добавь бота в группу
3. Отключи privacy mode: `@BotFather` → `/setprivacy` → выбрать бота → `Disable`

Без этого бот не увидит нажатия и сообщения в группе.

## Данные и совместимость

Бот переехал с прошлой версии (социальный рейтинг чата, `+rep`, `/catchup`, воскресный автопост) — весь этот функционал удалён. Старые таблицы в базе просто больше не используются ботом; при первом запуске новой версии они не трогаются и не удаляются.

## Ограничения текущей версии

- Правка уже сохранённого матча — только отмена последнего (`/undo` в истории)
- Один активный турнир на чат одновременно
- Составы команд не сохраняются между турнирами — собираются заново каждый раз
- Таблица рендерится текстом (моноширинный блок), не картинкой
