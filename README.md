# Турнирный бот PUBG / CS

Telegram-бот для дружеского чата, который ведёт турнирную таблицу PUBG и CS. Вместо ручного подсчёта убийств и побед в переписке всё вбивается кнопками прямо во время игры: бот копит историю матчей, считает таблицу, лигу за всё время и делает разбор от GPT.

Один Python-процесс, SQLite-файл, long polling. Для дружеского чата этого достаточно.

## Как это работает

1. `/menu` открывает меню.
2. `🏆 Новый турнир` — мастер по шагам, один вопрос на экран: игра (PUBG/CS) → режим (соло/командами) → состав. Название турнира не спрашивается отдельным шагом — подставляется само (сегодняшняя дата), поменять можно кнопкой `✏️ Название` на первом экране. Один раз в начале вечера.
3. Дальше бот сам ведёт табло текущего матча: у каждого живого игрока две кнопки — `➕ {Имя}` («кого убил») и `−` («от кого умер»). Кто выбывает — сразу пропадает с табло. Победитель никем вручную не назначается: как только остаётся один живой игрок (или, в командном режиме, одна живая команда), он и есть победитель.
4. `✅ Матч сыгран` — сохраняет катку, публикует обновлённую таблицу и сразу открывает табло следующего матча с тем же составом. Весь вечер — только кнопки.
5. `🏁 Завершить турнир` — финальная таблица, матрица «кто кого убивал», титулы вечера, разбор от GPT, голосование за MVP.

Смерти не вбиваются отдельно — умер тот, кого выбрали жертвой (или кто отметил «от кого умер»): `смерти = сыграно матчей − топов`, где топ = дожил до конца матча.

## Табло матча

- **`➕ {Имя}`** — «кого убил этот игрок?» → список живых соперников + «🎲 Рандома / не из наших» (убил постороннего в лобби — засчитывается убийство, никто не выбывает).
- **`−`** — «от кого умер этот игрок?» → список живых соперников + «🌀 Зона / падение» (смерть не от чужой руки — просто выбывает, никому не засчитывается убийство).

Оба варианта в итоге пишут одно и то же событие «убийство» — просто с разных концов: `+` у убийцы или `−` у жертвы дают одинаковый результат. Как только игрока выбрали жертвой (через любой из двух путей) — он пропадает с табло до конца матча.

- **`↩️ Отменить последнее`** — общая кнопка внизу, откатывает самое последнее записанное событие в этом матче (кто бы его ни нажал), возвращает жертву на табло.
- Если матч закончили раньше времени и живых осталось больше одного — топ получают все, кто остался в живых, без ошибки.

## Режим игры

- **Соло** — один экран со всеми известными игроками, тапаешь, чтобы включить/выключить, дальше «🚀 Начать». Победитель — последний оставшийся живым.
- **Командами** (2–4 команды) — по одному экрану на команду: «🔴 Команда 1: кто играет?» → тапаешь нужных → «▶️ Команда 2» → выбираешь следующих (список уже не показывает тех, кто занят в команде 1) → и так далее. Можно остановиться на 2 командах и не доходить до 4 — кнопка «🚀 Начать» появляется, как только заполнены хотя бы две. Победившая команда — та, у которой остался хоть один живой участник, определяется автоматически при сохранении матча. `+`/`−` предлагают выбрать только из **чужой** живой команды — своих не спутаешь и тимкилл физически не нажмёшь.

## Функции

- Таблица турнира: победы, убийства, KD, смерти, топы, среднее убийств за матч (К/М) — с процентами от общего
- Матрица «кто кого убивал» + «любимая жертва»
- Титулы вечера (Чемпион, Мясник, Снайпер, Танк, Клоун, Курица, Немезида)
- Текущие серии побед/поражений в конце каждого матча
- Лига за всё время: очки = топы×3 + убийства×1, ранги от 🥉 Бронзы до 👑 Легенды
- Прогнозы перед стартом турнира и подсчёт точности при завершении
- MVP-голосование по итогам турнира (нельзя голосовать за себя)
- Разбор от GPT: оценки 0–100 (хладнокровие / жестокость / игровой интеллект) + колонка «Живых» — среднее число живых соперников в момент килла (посчитано по фактам, не мнение GPT): меньше = добивает последних, больше = лезет в замес рано. В команде GPT отдельно просят сравнивать тиммейтов и называть, кто реально тащил победу
- Необязательные подколы от GPT после каждого матча (фоном, не тормозят игру)
- Гости, которых нет в чате (`➕ Добавить игрока`) — участвуют наравне со всеми
- Отменить последний матч — кнопка в «История»
- Предупреждение перед завершением турнира, если текущий (несохранённый) матч потеряется

## Как бот узнаёт участников

Telegram не даёт ботам получить список всех участников группы — это ограничение платформы, не бота. Игрок появляется в списке, когда:
- сам написал что-то в чат или нажал любую кнопку бота,
- кто-то **ответил (reply)** на его сообщение,
- кто-то кликабельно упомянул его (не просто `@username` текстом).

Для тех, кто в чате не пишет вообще (или кого нет в Telegram) — кнопка `➕ Игрок` (в настройке турнира) или `➕ Добавить` (в «Игроки»). Бот сам переключает поле ввода в режим ответа — просто печатаешь имя как обычное сообщение, ничего вручную нажимать не нужно. Несколько игроков сразу — через запятую («Хан, Вова»), без запятой всё, что напишешь, считается одним именем целиком (так «Хан Аднаев» не превратится в двух игроков).

## Меню

Главное меню — 4 кнопки: `🏆 Новый турнир` / `▶️ Вернуться`, `📊 Таблица`, `👥 Игроки`, `📜 История`. Реже нужные экраны спрятаны на один уровень глубже:
- с `📊 Таблица` — переходы на `🎖 Лига`, `🤖 Разбор`, `⚙️ Настройки`
- с `🎖 Лига` — переход на `🗂 Прошлые турниры`

Прямые команды-ярлыки (в автокомплите Telegram видно только английские варианты, но русские тоже работают, если ввести вручную):

- `/menu` (или `/бот`) — главное меню
- `/table` (или `/таблица`) — таблица текущего турнира
- `/match` (или `/матч`) — табло текущего матча
- `/league` (или `/лига`) — лига за всё время
- `/analyze` (или `/разбор`) — разбор от GPT
- `/about` — что умеет бот и как им пользоваться

## Настройки чата

Экран `⚙️ Настройки` (с `📊 Таблица`) — можно выключить (по умолчанию всё включено):
- 🤖 Подколы от GPT после матчей
- 🔮 Прогнозы перед турниром
- 🗳 MVP-голосование

## Переменные окружения

- `BOT_TOKEN` — токен бота от `@BotFather` (обязательно)
- `TZ` — часовой пояс, по умолчанию `Europe/Moscow`
- `DB_PATH` — путь к SQLite-файлу, по умолчанию `/data/bot.sqlite3`
- `LOG_LEVEL` — уровень логов, по умолчанию `INFO`
- `OPENAI_API_KEY` — ключ OpenAI для разбора и подколов; без него `/analyze` вернёт понятную ошибку, а подколы просто не будут приходить
- `OPENAI_SUMMARY_MODEL` — модель для разбора, по умолчанию `gpt-5-mini`

## Локальный запуск

Нужен Python 3.12+.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
BOT_TOKEN=... DB_PATH=./dev.sqlite3 OPENAI_API_KEY=... python -m bot.main
```

Тесты:

```bash
pytest
```

## Запуск на Railway

1. Залей проект в GitHub
2. Создай проект в Railway из репозитория — Railway соберёт контейнер по `Dockerfile`
3. Добавь volume, смонтируй в `/data`
4. Переменные: `BOT_TOKEN`, `TZ=Europe/Moscow`, `DB_PATH=/data/bot.sqlite3`, `LOG_LEVEL=INFO`, `OPENAI_API_KEY` (опционально)

Без volume база SQLite потеряется после каждого redeploy.

## Настройка Telegram

1. Создай бота у `@BotFather`, получи `BOT_TOKEN`
2. Добавь бота в группу
3. Отключи privacy mode: `@BotFather` → `/setprivacy` → выбрать бота → `Disable`

Без этого бот не увидит нажатия и сообщения в группе.

## Данные и совместимость

Бот переехал с прошлой версии (социальный рейтинг чата, `+rep`, `/catchup`, воскресный автопост) — весь этот функционал удалён. Старые таблицы в базе просто больше не используются ботом; при первом запуске новой версии они не трогаются и не удаляются.

## Ограничения текущей версии

- Правка уже сохранённого матча — только отмена последнего (кнопка в «История»)
- Один активный турнир на чат одновременно
- Максимум 4 команды за турнир
- Составы команд не сохраняются между турнирами — собираются заново каждый раз
- Таблица рендерится текстом (моноширинный блок), не картинкой
- Если в чате два игрока с одинаковым именем — в списках прогнозов/MVP их имена визуально совпадут (в базе считаются раздельно)
